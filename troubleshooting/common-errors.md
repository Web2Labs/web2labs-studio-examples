# Common Errors

- `missing_auth`: Set `WEB2LABS_API_KEY` or run onboarding.
- `no_api_credit`: Buy credits or use subscription bearer auth.
- `monthly_limit_reached`: Subscription monthly projects exhausted.
- `worker_unavailable`: Retry in a few minutes.
- `yt-dlp is not installed`: Install yt-dlp for URL workflows.
