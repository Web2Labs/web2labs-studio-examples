# Webhook Automation - Prompt Variations

## Simple Webhook

```
Upload ~/Desktop/episode.mp4 as youtube and send results to https://my-server.com/callback
```

## With Secret

```
Upload ~/Desktop/episode.mp4 as youtube with webhook https://my-server.com/callback and secret "my-secret"
```

## Check Status Later

```
What's the status of project p_w1x2y3?
```

## Batch with Webhooks

```
Process all videos in ~/recordings/ as youtube and send each result to https://my-server.com/callback
```

## Different Preset

```
Upload ~/Videos/stream.mp4 with gaming preset and webhook https://my-server.com/callback
```
