# Custom Configuration - Prompt Variations

## Disable Music

```
Edit ~/Desktop/episode.mp4 as youtube but with no music
```

## Limit Shorts

```
Edit ~/Desktop/episode.mp4 as youtube with only 5 shorts
```

## No Zoom

```
Edit ~/Desktop/episode.mp4 as youtube but disable zoom
```

## Subtitle Customization

```
Edit ~/Desktop/episode.mp4 as youtube with large subtitles and highlights
```

```
Edit ~/Desktop/episode.mp4 as youtube with minimal subtitles
```

## Mixed Overrides

```
Edit ~/Desktop/episode.mp4 as youtube but no music, 10 shorts max, and gentle cuts
```

## Cinematic Style

```
Edit ~/Desktop/episode.mp4 with the cinematic preset but keep subtitles on
```
