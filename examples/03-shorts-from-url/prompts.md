# Shorts from URL - Prompt Variations

## YouTube

```
Make shorts from https://youtube.com/watch?v=dQw4w9WgXcQ
```

## Twitch VOD

```
Turn this Twitch VOD into shorts: https://twitch.tv/videos/123456789
```

## With Download Path

```
Make shorts from https://youtube.com/watch?v=abc123 and save to ~/Shorts/
```

## Limit Clip Count

```
Make 5 shorts from https://youtube.com/watch?v=abc123
```

## Estimate First

```
How much would it cost to make shorts from https://youtube.com/watch?v=abc123?
```
