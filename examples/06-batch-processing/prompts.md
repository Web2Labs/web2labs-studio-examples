# Batch Processing - Prompt Variations

## Process All

```
Process all videos in ~/recordings/ as youtube videos
```

## Specific Preset

```
Process all .mp4 files in ~/recordings/ with the podcast preset
```

## Latest N Files

```
Process the latest 3 videos in ~/recordings/
```

## Mixed Presets

```
Process episode.mp4 as youtube and interview.mp4 as podcast from ~/recordings/
```

## Estimate Before Processing

```
How much would it cost to process all videos in ~/recordings/?
```

## With Download Path

```
Process all videos in ~/recordings/ as youtube and download each to its own folder in ~/exports/
```

## Rush Batch

```
Rush process all videos in ~/recordings/ — I need them by tonight
```
