# Twitch Automation - Prompt Variations

## Set Up Twitch Watcher

```
Watch my Twitch channel https://twitch.tv/my_channel for new VODs
```

## Set Up YouTube Watcher

```
Watch my YouTube channel https://youtube.com/@mychannel for new uploads
```

## With Custom Settings

```
Watch https://twitch.tv/my_channel with gaming preset, max 90 minute VODs, 3 per day
```

## Check for New Content

```
Check my watchers
```

## Check Specific Watcher

```
Check watcher #1 for new videos
```

## List All Watchers

```
Show my watchers
```

## Pause / Resume

```
Pause watcher #1
```

```
Resume watcher #1
```

## Remove

```
Remove watcher #1
```
